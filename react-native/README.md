# React Native journey sample

Use Node with the pinned dependencies, then `npm ci` and `npx expo prebuild --no-install`. The source sample includes a narrow patch for Expo's optional iOS toolbar on Xcode 27.0; `postinstall` applies it. The SDK package does not include this patch.

The sample resolves the native SDK from Rana's public Maven repository and hosted CocoaPods spec. Run `npx expo run:android` / `npx expo run:ios`. Set `RANA_PUBLIC_KEY` to a public app-restricted key before prebuild; it is written to native host configuration, not the JavaScript bundle. Re-run prebuild when it changes. The development client requires local-network access to Metro; that permission is distinct from GPS permission.

## Location and permissions

The sample uses the phone's real location. Set `RANA_PUBLIC_KEY` (a `pk_live_` public key) in the environment before `npx expo prebuild`; `app.plugin.js` reads it from there and writes it to native configuration. Permission strings and Android manifest entries come from the `locationWhenInUsePermission` / `locationPermission` plugin options in `app.json`. The app requests permission at launch (`PermissionsAndroid` on Android; on iOS the SDK's native provider asks when permission is undecided). If denied it shows "Location off — using Lagos" and falls back to Lagos Island. The idle map shows the native location dot with `firstFixZoom: 16.5`. The app learns its own coordinate from the SDK's `location` event, which reports each accepted fix. Directions stay disabled until the first fix.

While navigating, **Movement** chooses "Simulated" (default; the native provider is detached and the fake socket walks the route from the real origin, then the provider is reconnected on End) or "Device GPS" (the native provider keeps driving the puck with follow-heading tracking; simulator-played routes work too).

Tap the map to select a destination. The sample includes native live React markers, playback/pause/scrub/reset, draggable sheet/padding, day/night, direct/smooth and route-aware movement, detours, live directions, optional rerouting, simulated trace validation and offline operations. No booking or turn-by-turn application UI is provided.

Set `EXPO_PUBLIC_RANA_SMOKE=1` before `npx expo start --dev-client` for the real native service smoke check without a live key. It checks native identity headers, host HTTP callbacks, coordinates and stale handles, and displays `Native bridge passed` on success.

Local verification used the installed NDK 28.2.13676358 in the generated Android project instead of downloading Expo's default NDK. Native project output is regenerated by prebuild and is not committed.
